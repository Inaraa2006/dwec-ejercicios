## ¿Qué hace el programa?
Es una aplicación interactiva basada en consola que agrupa diversas herramientas prácticas de cálculo, conversión, series matemáticas y entretenimiento mediante un menú dinámico con prompt.

## ¿Cómo ejecutarlo?
1. Abre la carpeta ut02/a8-utilidades en tu editor
2. Abre el fichero index.html con Live Server
3. Interactúa con las opciones a través de las ventanas emergentes del navegador y los resultados se ven en la consola (F12)

## ¿Qué aprendí?

- A realizar commits en gitHub en cada actividad y actualizar si veía algún error.
